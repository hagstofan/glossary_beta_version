# Afleidd bæling / secondary suppression

## About the concept

  - **Concept ID:** HAG-1005 <br>
  - **Concept domain:** Rekjanleikavarnir 


## Definition

Þegar tiltekin gildi á breytu í gögnum eru falin svo ekki sé hægt að leysa út gildi sem eru aðalbæld. Birting gildanna myndi annars ekki brjóta gegn rekjanleikaviðmiðum.
