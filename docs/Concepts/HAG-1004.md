# Aðrir framleiðendur hagtalna / other national authorities

## About the concept

  - **Concept ID:** HAG-1004 <br>
  - **Concept domain:** Gagnastjórnun 


## Definition

Opinberar stofnanir sem bera ábyrgð á gerð innlendra hagtalna aðrar en hagstofa. Þessir aðilar geta einnig talist framleiðendur evrópskra hagtalna í samhengi Evrópska hagtölukerfisins.
