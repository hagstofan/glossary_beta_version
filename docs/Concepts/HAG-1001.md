# Aðgangur að gögnum / data access

## About the concept

  - **Concept ID:** HAG-1001 <br>
  - **Concept domain:** Gagnastjórnun 


## Definition

Aðgangur að gögnum felur í sér vinnslu gagna af hálfu Hagstofu Íslands, annarra opinberra aðila eða Eurostat, sem veitt hafa verið eða gerð aðgengileg af hálfu gagnaveitanda, í samræmi við tilteknar tæknilegar, lagalegar eða skipulagslegar kröfur.
